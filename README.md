# 🥬 卷心菜自由城 · Formal Edition 1.01

> **卷心菜精心制作 · 零外部依赖 · 即开即玩的 3D 开放世界 WebGL 游戏**

《**卷心菜自由城 Formal Edition 1.01**》（*Cabbage Liberty City*）是一款基于原生 **Three.js (ES Module)** 与 **WebAudio 实时合成** 打造的轻量级 3D 开放世界沙盒游戏。无需打包器、无需安装 `node_modules`，双击 `start.bat` 即可畅游 `16×16` 拓展海港都市、体验红紫玻璃幕墙东方明珠、全面柔滑化角色雕塑、六大武器系统、超跑氮气与武装直升机机炮、八幕主线三结局以及六贤深度思辨体系。

## 🌟 1.01 全面升级亮点 (What's New in 1.01)

1. **🎭 全模型曲面柔滑与材质重制 (`tools/smooth_models.mjs`)**
   - 针对所有 `BLD2`/`ROL5` 模型（**公园黄奶娃雕塑、飞鸟奶娃雕塑、神临巨像、大笑奶娃、奶娃路人、鲸鱼娘主角**）采用逆边长加权保守 **Taubin 保体积平滑**、零破洞单色点清洗，以及哑光素陶低糙度材质与缓和起落大笑动效。
   - 彻底重新整理 `laugh_naiwa.bin` 分区色块（完整保留亮黄主体、奶油肚腹、黑眯眼、暖棕掌垫与深红口腔/粉色舌头），并搭配柔边 `CanvasTexture` 水墨青烟精灵池。
   - **东方明珠球体红紫玻璃幕墙**：仅两枚巨型主球体与顶球采用高反光红紫玻璃幕墙材质，底座与三柱塔身保留哑光浅灰混凝土质感。

2. **🗺️ 16×16 拓展版图 & 唯一核心地标**
   - 城市由 `12×12` 扩建为 **`16×16`**，新增 **霓虹科技湾**（东北部）、**东海岸商业区**、4 座跨街霓虹门楼、8 座街区公园、6 座停机坪（含 3 座独立都市停机坪广场），并确保 **广州塔（小蛮腰）、东方明珠、环球金融中心、金茂大厦** 全城各自仅矗立 **1 座唯一地标**，采用 4×4（16 分区）视锥剔除合批保障流畅帧率。
   - 开设南侧 **观光木质栈桥** 与东侧 **翡翠港湾集装箱码头**（含海岸灯塔旋转光束、龙门吊、货柜掩体、停泊货轮与游艇）。

   - **角色物理与手感**：帧率无关阻尼 `damp`、长发/鲸尾二阶弹簧动力学、转身离心甩尾、落地缓冲压缩、土狼时间/跳跃缓冲、`Q` 键体能战术翻滚（带无敌帧与水花粒子）以及海港落水自动救助。

   - 六位哲学家升级为 **三段式深度思辨对话**，每次完成均永久解锁 **哲学家专属被动加护** 与 **自由城手记 (`J` 键 / `T → 7`)** 词条，神临终幕拓展为 **四幕哲理扣问**。

## 🎮 操作指南 (Controls)

| 按键 | 功能说明 |
| :--- | :--- |
| **`W` `A` `S` `D`** | 角色移动 / 车辆驾驶 / 直升机俯仰与转向 |
| **鼠标移动** | 自由转动视角 / 精确瞄准（开镜自动降敏） |
| **`Shift`** | 徒步冲刺 / 车辆激活 **氮气加速** / 直升机下降 |
| **`Q`** | 徒步 **战术翻滚闪避**（消耗体能+短暂无敌帧）/ 直升机左侧移 / 关闭对话或手记 |
| **`Space` (空格)** | 徒步跳跃 / 车辆手刹漂移 / 直升机拉升总距上升 |
| **`F` / `Enter`** | 上下车辆 / 抢车 / 驾驶直升机 / 高空跳伞 |
| **`V`** | 切换 **第一人称 (FPV 座舱/持枪)** 与 **第三人称** 视角 |
| **鼠标左键 / 右键** | 近战连击·射击·直升机双联机炮 / 精确瞄准（AWP 开镜） |
| **`1` ~ `6` / 滚轮** | 切换 6 类武器（近战 / 手枪 / 冲锋枪 / 霰弹枪 / 突击步枪 / 狙击枪） |
| **`R` / `H` / `L`** | 换弹 / 鸣笛 / 开关车灯与直升机探照灯 |
| **`E`** | 与 6 位剧情 NPC 或哲学家论道（柔烟+大笑）/ 触发市中心神临 |
| **`J`** | 打开/关闭 **自由城哲学与主线手记**（战绩、加护与主线提示） |
| **`T`** | 打开/关闭 **卷心菜手机**（支持键盘数字或鼠标点击操作 `1~7` 项服务） |
| **`Esc`** | 暂停游戏 / 返回主菜单切换【自由模式】与【赏金猎人模式】 |

## 🚀 快速开始 (Quick Start)

### 方式一：Windows 一键启动（推荐）
1. 确保电脑已安装 **[Node.js](https://nodejs.org/)**（建议 v18 及以上版本）。
2. 双击运行项目根目录下的 **`start.bat`**。
3. 终端启动本地 Gzip 静态服务（默认端口 `18081`）并自动在浏览器打开 `http://127.0.0.1:18081/`。

### 方式二：命令行启动（Windows / macOS / Linux）
```bash
node server.mjs
```
> 若需自定义端口，可指定环境变量：`PORT=8080 node server.mjs`。  
> 也可以使用 `npm run smooth` 重新对 `assets/*.bin` 运行 Taubin 柔滑修复管线。
