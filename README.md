# 🥬 卷心菜自由城 · Formal Edition 1.00

> **卷心菜精心制作 · 零外部依赖 · 即开即玩的 3D 开放世界 WebGL 游戏**

《**卷心菜自由城 Formal Edition 1.00**》（*Cabbage Liberty City*）是一款基于原生 **Three.js (ES Module)** 与 **WebAudio 实时合成** 打造的轻量级 3D 开放世界沙盒游戏。无需打包器、无需安装 `node_modules`，双击 `start.bat` 即可在浏览器中畅游集地标摩天楼、第一人称拟真座舱、六大哲学家论道与史诗级“神临 · 上帝之死 · 出神入化”于一体的自由城。

---

## ✨ 核心特色 (Features)

1. **🐳 鲸鱼娘主角 & 9 骨骼层级灵动物理动画**
   - 采用三视图自适应投影烘焙的 `1024×1024` 高清纹理图集（蓝发渐变、深海蓝女仆裙、金饰星纹与白围裙小鲸鱼徽章）。
   - **9 骨骼层级蒙皮系统 (`ROL5`)**：包含 `torso`（躯干）、`head`（头）、`legL/legR`（双腿）、`armL/armR`（双臂）、`tail`（鲸尾根部）以及子骨骼 **`hairBack`（随头部与步态二阶滞后飘动的长发）** 与 **`tailTip`（两段式波浪推进甩尾）**。
   - 根据顶点贴图色相自动识别长发与衣袖（`isHair` 色彩感知权重），彻底解决抬手带发与迈步僵硬问题；支持待机呼吸、轻快小跑、冲刺前倾、跳跃滞空、单手举枪瞄准与出拳动作平滑过渡。

2. **🏙️ 12×12 自由城地标建筑群 & 真实天空遮挡**
   - 四大地标高精度模型（**广州塔/小蛮腰**、**东方明珠**、**上海环球金融中心**、**金茂大厦**）与多座公园雕塑家庭（**黄色奶娃雕塑** & **黄身白翼绿黑双瞳飞鸟奶娃雕塑**）。
   - 动态昼夜循环、3D 体积积云与城市玻璃幕墙反射；太阳、日晕、月亮与夜晚繁星均启用深度遮挡测试（`depthTest: true`），高楼天际线呈现真实的日月星空遮挡关系。

3. **🏎️ 拟真第一人称载具座舱（跑车 / 直升机航电仪表）**
   - **跑车 / 轿车 / 警车 / SUV 第一人称驾驶舱**：方向盘带 12 点回正红标与金属中心徽标随转向丝滑联动、动态双指针仪表盘与 H 档杆动作、过弯离心力头部侧倾（G-force Lean）、加减速俯仰推背感、引擎与路面高频微震动、入弯视线预判与车身侧倾耦合。
   - **武装/观光直升机第一人称座舱**：配备倾斜航电仪表台，包含 **实时人工地平仪 / 姿态仪（Artificial Horizon）**、**空速表（ASI）**、**高度表（ALT）**、**升降率表（VSI）** 四联动态指针仪表，以及随升降联动的 **总距杆（Collective Lever）** 与 **周期变距杆（Cyclic Stick）**。

4. **🧠 六大哲学家论道 · 青烟与捧腹大笑**
   - 城中驻留 **亚里士多德、苏格拉底、庄子、笛卡尔、康德、尼采** 六位贤者（小地图紫色 `Φ` 标记），各自拥有专属服饰、法器与招牌肢体动作。
   - 每次与哲学家对话结束，两人之间升起一缕盘旋青烟，哲学家与玩家同步化身为 **捧腹大笑黄奶娃** 仰俯大笑并伴随合成笑声。

5. **✨ 史诗级【神临 · 上帝之死 · 出神入化】**
   - 集齐 6 枚哲思印记（或按快捷键 **`Shift + G`** / **`F9`** / 手机 **`T → 6`** 一键触发后门）即可在市中心召唤 **22 米高神圣飞鸟奶娃巨像** 伴随八道圣光环降临。
   - 经历神圣叩问后，神像崩解为 140 枚金耀碎片并化作金光洪流汇入玩家体内，揭示“**神本无相——那是你出神入化的哲学思想**”，解锁金色觉醒光环与全属性奖励。

6. **📦 极致包体优化 (`BLD2` / `ROL5`)**
   - 内置 `tools/pack_assets.mjs` 量化压缩管线，采用包围盒 16-bit 顶点量化、8-bit 法线/蒙皮权重与 Paeth 滤波纹理压缩，将原始 `~11 MB` 资源无损级压缩至 **`4.53 MB`**（配合 `server.mjs` 内置 Gzip 传输仅需 `~1.8 MB`），秒级加载、丝滑 60 FPS。

## 🚀 快速开始 (Quick Start)

### 方式一：Windows 一键启动（推荐）
1. 确保电脑已安装 **[Node.js](https://nodejs.org/)**（建议 v18 及以上版本）。
2. 双击运行项目根目录下的 **`start.bat`**。
3. 终端启动本地 Gzip 静态服务（默认端口 `18080`）并自动在浏览器打开 `http://127.0.0.1:18080/`。

### 方式二：命令行启动（Windows / macOS / Linux）
```bash
node server.mjs
```
> 若需自定义端口，可指定环境变量：`PORT=8080 node server.mjs`。  
> 也可以使用任意静态文件服务器（如 `npx serve .`、`python -m http.server 8080` 或 VS Code Live Server）托管本项目根目录。

## 🛠️ 模型重构建与二次开发 (Asset Pipeline)

如果你想修改模型或重新打包资源，可使用 `tools/` 目录下的零依赖 Node 脚本：

```bash
# 将原始高精度 BLD1 / ROL4 模型量化压缩为发布版 BLD2 / ROL5 格式
node tools/pack_assets.mjs --in <原始资源目录> --whale <鲸鱼娘输出目录> --out assets
```
